Comment utiliser cette page
  • 1. Choisissez un thème dans la colonne de gauche (même organisation que le menu du tableau de bord), puis une page.
  • 2. Choisissez si besoin un territoire (disponible sur toutes les pages), puis ajoutez les filtres proposés par la page avec Ajouter un filtre : une valeur par filtre.
  • 3. Cliquez sur Générer le lien, puis copiez-le ou ouvrez directement la page filtrée dans le tableau de bord.
  • Une fois la page ouverte, les filtres restent modifiables dans le tableau de bord. Pour un Tableau personnalisé, seuls les filtres sont transmis, pas la disposition du tableau.
