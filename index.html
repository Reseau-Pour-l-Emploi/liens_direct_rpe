Mes favoris du tableau de bord RPE

Pages filtrées et tableaux personnalisés, retrouvés en un clic
Comment ça marche
  • 1. Installez une fois le favori Assistant TdB RPE dans la barre de favoris de votre navigateur.
  • 2. Dans le tableau de bord, allez sur la page voulue et cliquez sur ce favori. L'assistant reconnaît la page :
  • page classique : il crée un favori 🔵 qui rouvre la page avec vos filtres (territoire, période...), en un clic ;
  • tableau personnalisé : il vous guide pour le mettre en forme, puis crée un favori 🟡 qui remet la disposition, les filtres et la période choisie, avec un export Excel automatique si vous le souhaitez.
  • 3. Faites glisser le favori créé dans votre barre de favoris.
Créez vos favoris directement dans le tableau de bordUn assistant s'affiche sur la page du tableau de bord et vous guide pas à pas : aucun aller-retour entre deux fenêtres.
