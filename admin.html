Relever automatiquement les pages et les filtres du tableau de bord

  1. Ouvrez le tableau de bord dans un nouvel onglet : Ouvrir le tableau de bord. Attendez que la page d'accueil soit affichée.
  2. Ouvrez la console du navigateur : touche F12, onglet Console.
  3. Cliquez sur , collez-le dans la console puis appuyez sur Entrée.
    Si le navigateur bloque le collage, tapez d'abord allow pasting (Chrome) ou autoriser le collage (Edge), puis Entrée.
  4. Laissez l'onglet au premier plan. Le script ouvre les pages une à une (environ 5 min). Un bandeau en bas à droite indique la progression et permet d'arrêter.
  5. À la fin, le fichier extraction-digdash-AAAA-MM-JJ.json est téléchargé. Importez-le dans l'onglet 2. Import.
À savoir
  • Le script lit la page sans rien modifier dans DigDash. Les pages DDAudit (fréquentation, système) sont exclues.
  • Il relève, pour chaque page, les listes de filtres présentes dans la page (volet "Filtres" compris) avec leurs valeurs, et la liste des territoires du panneau de filtres global.
  • Les valeurs relevées sont celles affichées au moment de l'extraction, pour le compte public. Relancez l'extraction après une évolution du tableau de bord (nouvelle page, nouveau filtre, nouveau millésime).
